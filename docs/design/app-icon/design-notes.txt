Floe App Icon（2026-10-20）

设计
- 用户最终选择 C3：淡冰蓝圆角底板与三条错落排列的蓝色浮条。
- 上、下浮条偏右，中间偏左，呼应菜单栏整理、排列与显隐功能。
- 底色亮度介于原 C 的近白色与 C2 的冰蓝灰之间，保留轻盈的蓝色层次。
- 外部保留透明背景，不改变已确认图案的形状、布局和颜色。

生成与源文件
- 使用内置 imagegen 生成 C，随后经过 C2、C3 两次底色调整。
- floe-icon.prompt.txt：C 初始生成提示词。
- candidates/c-organized-bars-v2.prompt.txt：C2 材质与底色调整提示词。
- floe-icon-refinement.prompt.txt：C3 最终底色调整提示词。
- floe-icon-master.png：最终 C3 母版，1254×1254 RGBA，与已确认的 candidates/c-organized-bars-v3.png 完全一致。
- candidates/ 保留 A、B、C、D 及 C2、C3 的图片与提示词；B 保留此前的 F 方案。

工程接入
- 使用 macOS sips 按 AppIcon.appiconset/Contents.json 导出十个图标资源。
- 像素尺寸覆盖 16、32、64、128、256、512、1024，重复尺寸分别对应不同点尺寸和倍率。
- Dock、Finder、设置侧栏和关于页通过应用图标资源读取新标识；README 页首沿用对应资源引用。
- 中英文 README 当前使用的浅色、深色设置页预览已同步为新标识；预览使用示例图标数据。
